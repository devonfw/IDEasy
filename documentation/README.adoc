== Search the documentation

To https://github.com/search?q=repo%3Adevonfw%2FIDEasy%20path%3Adocumentation%2F&type=code[search the documentation on GitHub],
sign in and add a command, variable, or error message after the repository and path filters.
For example, the following query finds the guide for a certificate error:

[source,text]
----
repo:devonfw/IDEasy path:documentation/ "PKIX path building failed"
----

Each release includes `IDEasy.pdf`.
To search the manual for your installed version, open the PDF and use `Ctrl+F` (`Cmd+F` on macOS).
For frequently asked questions, see https://github.com/devonfw/IDEasy/discussions/categories/q-a[Q&A in GitHub Discussions].

== Troubleshooting

* If setup fails, check the link:setup.adoc#installation-logs[installation logs].
  For errors during an `ide` command, see link:log.adoc[IDEasy logs].
* If downloads fail behind a corporate proxy, check the link:proxy-support.adoc#configuring-proxy-settings[proxy settings].
  If the proxy requires credentials, see link:proxy-support.adoc#authentication[proxy authentication].
* For `SSLHandshakeException` or `PKIX path building failed`, see link:proxy-support.adoc#tls-certificate-issues[TLS certificate issues].
* If Windows reports that a file is in use, see how to link:windows-file-lock.adoc#finding-processes-that-block-specific-files[find the process that locks the file].
* If macOS blocks IDEasy at startup, see the link:mac-gatekeeper.adoc#workaround[Gatekeeper workaround].
* For known tool issues on Windows, macOS, and Linux, see link:quality-status/quality-status.adoc[Quality Status].
