== Troubleshooting

* If installation fails, check the link:setup.adoc#installation-logs[installation logs]. See also the link:log.adoc[IDEasy logs].
* link:proxy-support.adoc[Proxy support] and link:proxy-support.adoc#configuring-proxy-settings[proxy settings for a corporate network].
* If the proxy requires credentials, see link:proxy-support.adoc#authentication[proxy authentication].
* For SSL or TLS certificate errors (`SSLHandshakeException`, `PKIX`),
  see link:proxy-support.adoc#tls-certificate-issues[certificate issues] and the link:proxy-support.adoc#truststore[truststore].
* If a file is in use on Windows, see how to link:windows-file-lock.adoc#finding-processes-that-block-specific-files[find the process that locks it].
* If macOS blocks IDEasy, see the link:mac-gatekeeper.adoc#workaround[Gatekeeper workaround].
* See link:quality-status/quality-status.adoc[Quality Status] for known issues across platforms.

== Search the Documentation

To search the docs on GitHub, open
https://github.com/search?q=repo%3Adevonfw%2FIDEasy%20path%3Adocumentation%2F&type=code[GitHub Code Search]
and add the main words after the filters. Separate words match in any order in the same file.
Use quotes around a phrase if you want an exact match. Sign in to search the default branch.

[source,text]
----
repo:devonfw/IDEasy path:documentation/ create commandlet
----

To search a local checkout, run the following command from the repository root. Use Git Bash on Windows.
Change the words after `-e` to list files that contain both terms.

[source,shell]
----
git grep -l -i -F --all-match -e 'create' -e 'commandlet' -- 'documentation/*.adoc'
----
