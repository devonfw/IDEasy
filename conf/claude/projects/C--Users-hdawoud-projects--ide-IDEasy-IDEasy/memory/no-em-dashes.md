Do not use em dashes (—) in any text you write for the user. Use commas, colons, or split the sentence instead.

**Why:** User stated this explicitly as a writing style preference.

**How to apply:** When composing PR descriptions, comments, commit notes, or any prose, replace em dashes with other punctuation (comma, colon, or a new sentence). Applies to all user-facing text.
